# MOH On-Duty Health Centers

An unofficial, searchable directory of the Saudi Ministry of Health's on-duty and extended-hours primary care centers, with live "open now" status on Riyadh time.

Live site: https://gpmc2030.github.io/moh-centers/

Data source: [MOH On-Duty Healthcare Centers](https://www.moh.gov.sa/HealthAwareness/On-Duty-Healthcare-Centers/Pages/default.aspx), extracted 19 Oct 2026. Confirm hours on the MOH page before relying on them. For emergencies call 997.
